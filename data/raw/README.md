# Datos de entrada

Descargar `heart.csv` desde el [Heart Failure Prediction Dataset de Kaggle](https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction) y dejarlo en esta carpeta.

La ruta esperada por el proyecto es:

```text
data/raw/heart.csv
```

El CSV se excluye de Git mediante `.gitignore`. Una vez ubicado, se revisarán sus columnas y calidad antes de entrenar modelos.
